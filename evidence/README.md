# 증빙 기준 변경

이 저장소의 기준은 MAI_SMA_학생전달.zip의 정비 문서 1,000건 학생 패키지입니다.

- `duckdb/`: 새 학생판의 실제 실행 화면을 추가할 위치. 아직 새 캡처는 없습니다.
- `previous_300_version/`: 이전 300건 앱의 화면 3장과 당시 통합 PDF. 최종 1,000건 기준의 증빙이 아닙니다.
- `colab/`: 기존 MNIST GPU 실행 사진 5장. 별도 실습이므로 유지했습니다.
- `codex/`: 기존 개발 대화 3장. 이번 학생판 이식/점검 과정의 실제 대화 2장을 추가할 수 있습니다.
- `app/`: 기존 300건 완성 앱 보조 사진. 새 학생판 화면과 구분해야 합니다.

기존 캡처의 300이나 33을 1000이나 75로 고쳐서 새 실행 증빙처럼 만들지 않았습니다.
학생판 DB와 검색문맥은 공개 저장소에 포함하지 않습니다.
