## 해석 범위
집계형 정답률과 절차형 인용 충실도는 분모가 달라 하나의 전체 정확도로 합치지 않습니다.
인용 exact는 문자열이 지목한 기록과 일치한다는 뜻이며, 답변의 의미 정확성·완전성·작업 안전성을 보증하지 않습니다.
JSON 유효와 단계 산출도 서로 다른 지표입니다. 답변을 생성하지 못한 문항은 생성 실패로 별도 기록합니다.
오답이나 형식 오류를 정답으로 수정하지 않았고, 실패한 문항만 골라 유리한 결과로 대체하지 않았습니다.
실제 데이터 규모는 학생용 표본 1,000문서이며 전체 선대 DB나 다른 모델 실험과 직접 동일시할 수 없습니다.
