3B 담당 제출 마무리 순서

1. GitHub에 올릴 자료
GitHub_3B담당_최종자료.zip을 먼저 압축 해제합니다.
그 안의 MAI_SMA_1000_GitHub 폴더를 열고 README.md, app, tools, eval,
notebooks, evidence, results 등 내부 파일과 폴더를 저장소에 업로드합니다.
ZIP 하나만 올리기보다 소스를 바로 열어 검토할 수 있게 내부 파일을 올립니다.
README.md가 저장소 첫 화면에 보여야 합니다.

2. DuckDB 증빙
새 학생판 MAI_SMA_1000.exe로 실행한 화면을 사용합니다.
전체 정비 문서 수를 질문하고 실제 결과 1,000과 SQL이 함께 보이게 촬영합니다.
다른 집계 질문도 실행하되 오답이나 오류가 나오면 그대로 결과와 한계를 기록합니다.
기존 300건 앱 화면은 새 1,000건 평가 증빙으로 대신하지 않습니다.
새 캡처를 evidence/duckdb/에 넣습니다.

3. Colab 증빙
evidence/colab/의 실제 MNIST GPU 실습 화면 5장을 유지합니다.
MNIST CNN 학습과 Llama 3.2 3B 추론 평가는 서로 다른 실습입니다.

4. Codex 증빙
evidence/codex/의 기존 실제 대화는 3장입니다.
이번 학생판 적용 및 3B 평가 결과 정리 대화에서 실제 화면 2장을 추가합니다.
대화 내용과 결과를 편집해 성공한 것처럼 만들지 않습니다.

5. 공개 자료 최종 확인 및 제출
DB 파일, 검색 pickle, 평가 질문/정답 원문, 정비 문맥 및 모델 응답 원문은 올리지 않습니다.
비공개_학생판1000_실행자료.zip과 비공개_3B_전체평가_원자료.zip은 Public GitHub에 올리지 않습니다.
results/llama32_3b/는 원문을 제외한 지표, 그림, 보고서이므로 공개용입니다.
저장소 공개 설정을 Public으로 확인하고 로그아웃 상태에서도 README와 소스가 보이는지 확인합니다.
최종 제출란에 https://github.com/계정명/저장소명 형식의 저장소 주소를 제출합니다.
제출 양식에서 요구하면 보고서 PDF도 함께 첨부합니다.

이 폴더는 업로드 준비 자료입니다. GitHub 업로드나 제출 완료를 의미하지 않습니다.
